# single-cell-rnaseq-workshop
A hands-on workshop on single-cell RNA-seq analysis, from raw FASTQ files to gene expression analysis using Cell Ranger and Scanpy.

## Learning objectives

By the end of this workshop, participants will be able to:

- Understand the main steps of a scRNA-seq workflow.
- Connect to a remote Linux server using SSH.
- Process 10x Genomics FASTQ files using Cell Ranger.
- Understand the structure of a gene expression count matrix.
- Perform downstream analysis using Python and Scanpy.
